# Documentation

Documentation source for the MATLAB yfinance API.

Current topics:

- Installation
- Historical prices
- Multi-symbol downloads
- Corporate actions
- Quote metadata
- Fundamentals
- Options
- Search and screener APIs
- Live streaming
- Parity and release hardening

Build the generated API reference from the repository root:

```matlab
buildtool docs
```

Generated output:

- [API_REFERENCE.md](API_REFERENCE.md)
- [GETTING_STARTED.md](GETTING_STARTED.md)
- [PARITY_AUDIT.md](PARITY_AUDIT.md)
